# 桌面便签 · 产品宣传视频脚本

> 依据 `design/README.md` 与 `design/preview/*` 的视觉稿整理。
> 视觉关键词：暖黄便签纸、纸纤维、撕边胶带、手写标题、细虚线分隔、灰棕墨色、浅红强调色。

---

## 一、视频规格

| 项目 | 建议 |
| --- | --- |
| 用途 | 官网首页、Microsoft Store 宣传片、社交媒体短片 |
| 主版本时长 | 30 秒（另附 15 秒剪辑版） |
| 画幅 | 16:9（1920×1080）主版；9:16（1080×1920）适配竖屏 |
| 帧率 | 24 或 30fps；UI 录屏建议 60fps 采集后再适配 |
| 语言 | 中文旁白 + 中文字幕；可另出无旁白版 |
| 风格 | 安静的晨间桌面、真实纸感 UI、克制运镜、轻钢琴 + 纸张音效 |
| 制作方式 | **环境与氛围用实拍/AI 生成，功能画面用实机录屏**（避免 AI 生成文字变形） |

### 色彩与视觉基准

- 便签纸：`#F8E8A9`（黄）
- 墨色：`#5E4B21`
- 强调色：`#B4402F`（紧急/逾期）
- 分隔：`1px dashed rgba(94,75,33,.22)`
- 标题与任务名：楷体/手写体；正文：微软雅黑
- 关键质感：纸纤维、撕边半透明胶带、便签阴影、轻微纸张起伏

---

## 二、创意概念

**主题：一张便签，装下今天。**

不展示冰冷的软件界面，而是把便签应用当成桌面上真实存在的“一张纸”：

- 清晨的桌面、一杯咖啡、铅笔和纸张的轻响；
- 便签从桌面自然出现，分类、任务、节点、规则像纸上的手写内容一样逐层展开；
- 功能演示全部用真实 UI，镜头只做温和推近、跟随和局部放大；
- 结尾回到安静的桌面，强调“数据只留在这台电脑”。

---

## 三、声音设计

- **配乐**：轻钢琴 + 木琴/八音盒点缀，70–80 BPM，无歌词，整体音量约 -18 LUFS。
- **音效**：翻纸、胶带撕开、鼠标点击、键盘输入、轻微提示音。
- **旁白**：温柔自然的中性/女声，语速偏慢，不要播音腔；旁白约 -16 LUFS。
- **字幕**：短句为主，手写体标题 + 雅黑正文；避免整段文字堆叠。

## 四、30 秒分镜脚本

### 镜头 1｜0:00–0:04｜开场：桌面上的便签

- **画面**：清晨暖光下的木纹桌面，背景有虚化的咖啡杯和绿植阴影。一张黄色便签窗口从画面边缘轻轻滑入中央，纸面纤维、顶部撕边胶带、便签阴影清晰可见。
- **运镜**：极慢推近（约 5%），浅景深，镜头轻微手持呼吸感。
- **屏幕文字**：手写体「桌面便签」，下方小字「一张便签，装下今天」。
- **旁白**：「一张便签，装下今天。」
- **声音**：纸张轻响 + 钢琴单音。
- **转场**：便签左侧撕边纸纹横向划过画面，带出下一镜。

---

### 镜头 2｜0:04–0:10｜首页：分类与待办

- **画面**：实机录屏放大居中。顶部「工作 / 生活 / 家人」分类标签依次浮起；当前分类高亮；任务列表出现带紧急胶囊和进行中圆点的任务；光标勾选一条任务；点击「+」快速新建。
- **运镜**：界面像纸片一样轻微浮动；镜头跟随光标做 1.1–1.2 倍局部放大。
- **屏幕文字**：手写体「分类 / 待办 / 一屏看清今天」。
- **旁白**：「工作、生活、家人，各自一张清单；重要的，一眼看见。」
- **声音**：鼠标点击、勾选纸面点击声。
- **转场**：一条虚线从右向左延伸，切入任务详情。

---

### 镜头 3｜0:10–0:16｜详情：节点、进度、生命周期

- **画面**：打开「整理 Q4 报销单」详情页。节点列表依次出现：已完成节点（勾选 + 删除线）、进行中节点、带红色「已延迟」胶囊的节点；展开进度输入「记录当前进展…」；生命周期记录向下滚动。
- **运镜**：自上而下平滑滚动，节点处轻微停顿并放大。
- **屏幕文字**：手写体「节点 · 进度 · 生命周期」。
- **旁白**：「拆成节点，记录进度，每一步都有迹可循。」
- **声音**：键盘轻敲、纸面勾选、滚动摩擦声。
- **转场**：生命周期时间轴化作细虚线，延展为下一镜的规则列表分隔线。

---

### 镜头 4｜0:16–0:21｜周期规则：到点自动出现

- **画面**：进入「周期任务规则」，新建规则；选择所属分类，设置每日/按周和生成时间，保存；镜头切到对应分类，当天的实例任务自动出现在列表中。
- **运镜**：三段式 match cut：规则表单 → 分类选择 → 自动生成任务；每段约 1.5 秒。
- **屏幕文字**：手写体「固定的事，交给规则」。
- **旁白**：「固定的事，交给周期规则；到点出现，不忘记。」
- **声音**：轻提示音、保存点击。
- **转场**：列表卡片侧滑，进入历史与整理。

---

### 镜头 5｜0:21–0:26｜历史、合并、数据管理

- **画面**：快速蒙太奇：
  1. 历史任务页：分类筛选、任务名搜索、点击「选择」出现勾选框，全选并批量删除；
  2. 任务合并：勾选两个任务，输入合并后的名称，确认后生成一个待完成的新任务；
  3. 数据管理：显示数据版本，点击导出 JSON，再演示导入预览。
- **运镜**：三个短镜头各约 1.6 秒，轻微推近；用纸翻页或虚线擦拭转场。
- **屏幕文字**：四个手写小标签依次出现——「筛选 / 批量 / 合并 / 备份」。
- **旁白**：「历史能筛能批量整理；多个任务，合成一件；数据也能随时带走。」
- **声音**：连续轻点击 + 短促 whoosh。
- **转场**：低强度纸翻页，进入外观设置。

---

### 镜头 6｜0:26–0:30｜外观与收尾

- **画面**：侧滑设置面板，五个主题色点依次点选（黄 → 蓝 → 绿 → 粉 → 白），便签纸色随之变化；切换手写字体；输入自定义签名；最后回到暖黄色。镜头拉远，整张便签安静地落在桌面上。
- **屏幕文字**：中段手写体「换一种纸，换一种心情」；结尾卡「桌面便签 / StickyNote」+「本地存储 · 无需登录 · 免费使用」。
- **旁白**：「换一种纸，换一种心情。数据，只留在这台电脑。桌面便签。」
- **声音**：钢琴收尾、纸张落定声。
- **转场**：画面轻微降亮，产品名与图标停留 1 秒后淡出。

## 八、AI 生成素材提示词

> **重要制作建议**：镜头 2–5 的 UI 与中文文字必须使用实机录屏或设计稿动效，不要让 AI 直接生成界面文字，否则极易出现错字和乱码。AI 适合生成镜头 1、片头片尾、纸张转场和桌面氛围。

### 1. 开场桌面氛围图 / 视频

```text
温暖清晨的木质桌面，浅米色桌垫，虚化的咖啡杯与绿植阴影；一张带纸纤维的暖黄色便签静静放在画面中央，顶部有半透明撕边胶带，便签边缘微微翘起；柔和侧逆光，浅景深，真实纸感，安静克制的高级感，16:9，电影感，缓慢推近，画面中不要出现任何文字。
```

### 2. 纸张转场素材

```text
微距特写：暖黄色便签纸的撕边从画面左侧划过，纸纤维和细微毛边清晰可见，带轻微纸张起伏与阴影；柔和自然光，背景为虚化的暖色桌面，干净、克制、真实，16:9，慢动作，不要出现文字。
```

### 3. 结尾桌面空镜

```text
清晨暖光下的简洁桌面，暖黄色便签安静地放在中央，周围留出大量干净空间，咖啡杯和铅笔在远景中轻微虚化；柔和阴影，浅景深，宁静、温暖、日常感，16:9，极慢横移，画面中不要出现任何文字。
```

### 4. 主题色变化转场（可选）

```text
同一张桌面便签纸从暖黄色平滑过渡为浅蓝色、浅绿色、浅粉色和米白色，纸张纹理和撕边胶带保持一致，光线柔和，颜色过渡自然，无文字，16:9，平滑缓慢的变化。
```

## 九、制作执行清单

1. **实机录屏**：按 2 倍或 4 倍分辨率采集以下场景：
   - 首页分类切换、勾选任务、添加任务；
   - 任务详情节点完成、添加进度、生命周期滚动；
   - 周期规则新建并选择分类；
   - 历史任务分类筛选、搜索、多选批量删除；
   - 任务合并确认；
   - 数据管理导出与导入预览；
   - 主题/字体/签名切换。
2. **素材处理**：录屏使用 60fps，后期做 1.0–1.2 倍柔和推近；隐藏系统任务栏与鼠标拖影。
3. **合成**：将实机录屏嵌入桌面场景，使用纸张阴影与轻微透视，避免悬浮感过强。
4. **字幕**：手写体仅用于标题与关键词，正文用雅黑；控制在画面下方安全区内。
5. **音频**：配乐与音效需可商用授权；旁白与字幕轴对齐，结尾留 1 秒安静。
6. **导出**：16:9 主版 H.264/H.265，1080p 或 4K；9:16 竖版单独构图，不直接裁切横版。
