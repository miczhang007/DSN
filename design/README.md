# 桌面便签 UI 改版设计稿（v1.4.3 基线）

本目录存放桌面便签主界面改版的视觉稿与设计说明。设计稿为示意图，用于确认方向与信息结构；图中文字为占位示意，实际文案以现有产品文案为准。

- 视觉稿：`mockups/01-home-task-list.png` ~ `07-settings-panel.png`
- 当前代码基线：`src/App.vue` + `src/components/*` + `src/composables/*`（v1.4.3，单窗口 360×520）

---

## 一、页面梳理（现状）

应用只有一个便签窗口，所有内容都在同一个窗口内切换 `view` 状态，没有独立窗口或多级页面栈。

### 1. 主界面（`view = home`）
- 结构：便签头部（`待办` 标题 + `+` 添加 + `⋮` 菜单）→ 分类标签卡片行 → 任务列表 → 底部（条目数 + 品牌名）
- 任务行：左侧勾选圈、`任务标题`、元信息行（`周期任务`、下一步节点、`已延迟`、`紧急`、`开始时间`）
- 交互：点击勾选完成（含完成时间确认）、整行点击进详情、按住拖动排序、进行中标题前有圆点
- 空状态：`今天还没有待办` + `添加一个`

### 2. 任务详情（`view = detail`）
- 摘要区：标题、状态胶囊、`紧急`、`周期规则`入口、开始时间、截止时间
- 操作区：`挂起 / 激活 / 进行中 / 已完成 / 撤销完成 / 归档 / 任务编辑 / 添加进度` 共 8 个平铺文字按钮
- 展开区：任务编辑（标题、紧急、未来任务、开始时间）、节点列表（勾选、拖动排序、行内编辑、删除）、进度记录（文本 + 时间）
- 底部：`生命周期` 事件流（创建、状态变更、进度更新；进度类事件可删除）

### 3. 新建任务（`view = add`）
- 字段：任务名、`周期任务 / 紧急 / 未来任务` 复选、未来任务开始时间
- 周期任务额外字段：时间范围（长期/指定日期）、开始/结束日期、频率（按日/按周/按月）、周几多选、重复次数、任务生成时间
- 一次性任务可先加节点（名称 + 计划日期时间）
- 提交按钮：`添加任务`

### 4. 历史任务（`view = history`）
- 归档任务列表：标题 + `已完成/未完成 · 时间`
- 行尾 `⋮` 展开操作：`撤销完成 / 已完成 / 撤销归档 / 删除`

### 5. 周期任务规则（`view = recurring-settings`）
- 规则列表：标题 + 频率摘要 + 状态（生效中/已作废）
- 行尾 `⋮` 展开：`编辑规则 / 作废 / 删除`

### 6. 规则详情（`view = recurring-setting-detail`）
- 三块内容：设置信息、操作日志、相关任务（含已完成次数）

### 7. 规则编辑（`view = recurring-setting`）
- 与新建表单的周期字段基本一致 + `保存设置`

### 8. 分类（`view = categories`）
- 顶部折叠的 `添加分类` 按钮 → 展开成表单
- 分类列表：点击切换当前分类；每行 `改名 / 删除`；首页顶部标签卡片支持直接切换与 `+` 新增入口

### 9. 设置（`AppMenu` 侧滑菜单）
- 导航：历史任务、周期任务规则、分类管理、产品简介、退出
- 外观：便签大小（小/中/大）、主题（黄/蓝/绿/粉/白）、位置（居中/右上/右下/左上/左下）
- 开关：开机自启动、极简模式

### 10. 全局组件
- `ConfirmDialog`：完成时间选择、二次确认
- `AppNotice`：轻提示

### 现状问题
1. **跳转偏多**：新建、历史、规则、分类、详情各占一整屏，做完一步要返回。
2. **操作暴露过度**：详情页 8 个同级按钮，主次不清。
3. **表单沉重**：新建任务把周期配置、节点编辑全铺开，一次性任务也被大量字段包围。
4. **外观仍是网页控件**：下拉框、复选框排布密集，缺少"纸"的质感。
5. **列表承载不足**：主界面看不到已完成项，历史无分组。

## 二、设计原则

1. **一张便签到底**：只保留一个窗口，所有层级在原位展开/收起，不再跳整页。
2. **像一张真便签**：纸质底色 + 轻微纹理 + 胶带/阴影，手写体标题，细虚线分隔；控件贴近纸面而非网页表单。
3. **一屏一件事**：主界面只做"看 + 勾 + 加"；进详情才出现节点与时间线。
4. **主操作唯一**：每屏至多一个实心按钮，其余为文字按钮或溢出菜单。
5. **即时反馈**：开关、主题、排序等改动立即生效，用轻提示代替弹窗。

## 三、设计稿说明

### 01 主界面 · 待办列表
- 头部：`待办` 使用手写体，右侧仅保留 `+` 与 `⋮` 两个细线图标。
- 任务行：左勾选圈 + 手写体标题；元信息一律降为小一号灰棕色（`周期任务`、`下一步 提交财务 · 明天`、`开始 11-05 09:00`）。
- `紧急` 用浅红底胶囊，`已延迟` 同色系，其余标签不抢色。
- 进行中用标题前的实心小圆点表示，不额外占一行。
- 底部留一行 `已完成 2 项` 的折叠入口，展开即在原位显示已完成项（原地置灰、可撤销完成）。
- 顶部新增一行分类标签卡片：`工作` / `生活` / `家人` / `+`，当前分类浮起、其余虚线降调；点击即切换，不跳页面。
- 页脚只保留 `4 项` 与品牌名，不再承担分类切换。

### 02 任务详情（原位展开）
- 顶部 `‹ 待办` 返回，标题升为便签最大字号。
- 状态胶囊 + `紧急` + `周期规则` 链接一行排列。
- 操作收敛为一行胶囊式文字按钮：`挂起 / 进度 / 编辑 / 归档`；`已完成` 由标题右侧的勾选圈承担，次要动作进 `⋮`。
- `节点` 列表：勾选圈 + 标题 + 计划/完成时间；完成项删除线，逾期用红色 `已延迟`。
- 底部直接内嵌 `记录当前进展…` 输入条 + `添加进度`，不再跳转表单。
- `生命周期` 压成两行灰色时间信息，需要时再展开。

### 03 新建任务（页内快速输入）
- 标题占位即输入框（手写下划线），先写任务名，其余选项都是可选。
- `周期任务 / 紧急 / 未来任务` 改为三个轻量开关，默认全关，避免一次面对大表单。
- 打开 `周期任务` 才在原位展开频率、日期、生成时间；关闭即收起。
- 节点用一行 `添加节点名称` 虚线输入 + `添加`，可连续追加。
- 底部一个全宽实心按钮 `添加任务`。

### 04 历史任务
- 按 `今天 / 昨天 / 更早` 分组（设计稿示意为单组）。
- 行尾 `⋮` 展开的行内操作条替代弹窗：`撤销完成 / 删除`。
- 底部灰色提示 `今天没有新的历史记录`，不再用空状态大块留白。

### 05 周期任务规则
- 规则卡片直接用分隔线切分，不做卡片描边。
- 每行右侧常驻 `编辑 / 作废` 文字操作；`已作废` 项整体降灰，仅留 `删除`。
- 底部 `+ 新建周期任务` 作为虚线按钮，入口常驻。

### 06 分类
- 当前分类整行浅色高亮 + 手写对勾；点击其他分类即切换。
- `改名 / 删除` 只在行内以极小灰字出现，不占独立按钮位。
- 底部虚线下划输入 `新分类名称` + `添加`，一步完成新增。

### 07 设置面板（覆盖式侧滑）
- 从右侧滑入、覆盖约 2/3 便签，左侧任务列表仍露出（保留上下文）。
- 一级入口三条文字：`历史任务 / 周期任务规则 / 分类`。
- 外观区：5 个色点直接点选（当前色带描边环），大小用 `小 中 大` 段控，位置用轻量下拉。
- 开关：`开机自启动 / 极简模式` 右侧滑杆，即时生效。
- 底部 `产品简介`、`退出`（退出用低饱和红），不再与功能项混排。

## 四、设计令牌（建议沉淀到 `src/styles.css`）

| 类别 | 取值 |
| --- | --- |
| 便签纸 | 黄 `#F8E8A9` / 蓝 `#CCE4F7` / 绿 `#D7EDC6` / 粉 `#F7D0DC` / 白 `#F7F4E9` |
| 面板纸 | `#FFF4C7`（设置面板、内嵌卡片） |
| 墨色 | 主 `#5E4B21`，次 `rgba(94,75,33,.62)`，禁用 `rgba(94,75,33,.38)` |
| 强调 | 紧急/逾期 `#B4402F`，底 `rgba(180,64,47,.12)` |
| 分隔线 | `1px dashed rgba(94,75,33,.22)` |
| 圆角 | 便签 10px，控件 8px，胶囊 999px |
| 间距 | 8 的倍数；行高 1.5；任务行上下 10px |
| 阴影 | 便签 `0 18px 40px rgba(60,50,30,.18)`；面板 `-8px 0 24px rgba(60,50,30,.12)` |
| 纹理 | 3% 噪点叠加 + 顶部胶带（`::before`，半透明米白） |
| 字体 | 标题/任务名：`KaiTi, "楷体", "Segoe Print", cursive`；正文：`"Microsoft YaHei UI", "Microsoft YaHei", sans-serif`；数字与计数用正文同字号、字重 500 |

字体说明：为控制安装包体积，优先使用系统自带的楷体；若要更统一的手写观感，可考虑子集化引入霞鹜文楷（约 2–4 MB），需单独评估。

## 五、落地建议（分三步，改动范围可控）

**P0 视觉层（不改交互）**
- `src/styles.css`：把上表令牌化，替换现有零散色值与阴影；任务行、胶囊、虚线分隔统一。
- `src/components/AppMenu.vue`：改为覆盖式面板（色板 + 段控 + 开关），替换三个下拉框。
- 改动后按规范更新 `src/App.vue` 的 `versionLabel`。

**P1 交互层（减少跳转）**
- `src/composables/useTaskDetail.js` + `App.vue`：详情改为原位展开，操作按钮收敛为一主三辅 + 溢出菜单。
- `src/composables/useTaskCreation.js`：新建改为页内快速输入，周期字段折叠。
- `src/composables/useHistory.js`：历史按日期分组，行内操作条替代弹窗。

**P2 结构层**
- `src/composables/useRecurringTaskSettings.js`：规则行内编辑，去掉规则编辑整页。
- `src/composables/useCategories.js`：分类行内改名 + 底部常驻新增输入。
- 顶部分类标签卡片（`App.vue` 的 `.category-tabs`）：**已在 v1.4.3 实现**，切换即加载，末尾 `+` 进入分类管理。
- 主界面增加 `已完成 N 项` 折叠区（需同步调整极简模式规则）。
